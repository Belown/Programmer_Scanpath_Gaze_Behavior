# Model Analysis

1. **Random Effects**: Random intercept SDs for exp_a = 0.01963 and exp_b = 0.02475; residual SD = 0.06290.
Adjusted ICC = 0.201, meaning that ~20% of the total variance in score is attributable to stable between-participant differences (moderate individual differences).
2. **Nakagawa R²**: Marginal R² = 0.378; Conditional R² = 0.504. Fixed effects (expertise_a, render_a, and their interaction) explain ~38% of the variance; participant-level random effects account for an additional ~13%.
3. **Post-hoc inference**:
   - expertise_a
     - Beginner ≈ Intermediate (Δ ≈ +0.0248, p = .0503; marginal, not reliably significant after Tukey adjustment)
   - render_a
     - r1 > r2 (Δ ≈ +0.1142, p < .0001)
     - r1 > r3 (Δ ≈ +0.1030, p < .0001)
     - r2 ≈ r3 (ns)
  There is only weak (borderline) evidence that Beginners score higher than Intermediates overall, and no reliable difference between r2 and r3.
