# Model Analysis

1. **Random Effects**: Random intercept SDs for exp_a = 0.01226 and exp_b = 0.01087; residual SD = 0.04047. Adjusted ICC = 0.141, meaning that ~14% of the total variance in score is attributable to stable between-participant differences (small-to-moderate individual differences).
2. **Nakagawa R²**: Marginal R² = 0.0027; Conditional R² = 0.1432. PairType explains <1% of the variance; participant-level random effects account for an additional ~14%.
3. **Post-hoc inference**:
   - LN ≈ LM (Δ ≈ −0.0060, p = .287)
   - LN ≈ MN (Δ ≈ −0.0022, p = .964)
   - LN ≈ HN (Δ ≈ −0.0007, p = 1.000)
   - LN ≈ HL (Δ ≈ −0.0020, p = .999)
   - LN ≈ HM (Δ ≈ −0.0040, p = .968)
   - LM ≈ MN (Δ ≈ +0.0038, p = .898)
   - LM ≈ HN (Δ ≈ +0.0053, p = .914)
   - LM ≈ HL (Δ ≈ +0.0039, p = .961)
   - LM ≈ HM (Δ ≈ +0.0020, p = .997)
   - MN ≈ HN (Δ ≈ +0.0014, p = .999)
   - MN ≈ HL (Δ ≈ +0.0001, p = 1.000)
   - MN ≈ HM (Δ ≈ −0.0018, p = .999)
   - HN ≈ HL (Δ ≈ −0.0013, p = .999)
   - HN ≈ HM (Δ ≈ −0.0032, p = .939)
   - HL ≈ HM (Δ ≈ −0.0019, p = .981)
  Conclusion: There is no evidence that PairType (LN, LM, MN, HN, HL, HM) reliably affects score. Fixed effects contribute negligibly to explained variance, and the observed variability is dominated by between-participant differences rather than by pair composition.
