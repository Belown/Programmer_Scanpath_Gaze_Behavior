# Model Analysis

1. **Random Effects**: Random intercept SDs for exp_a = 0.02158 and exp_b = 0.02045; residual SD = 0.03621. Adjusted ICC = 0.403, meaning that ~40% of the total variance in score is attributable to stable between-participant differences (substantial individual differences).
2. **Nakagawa R²**: Marginal R² = 0.3585; Conditional R² = 0.6169. Fixed effects (expertise_a, render_a, and their interaction) explain ~36% of the variance; participant-level random effects account for an additional ~26%.
3. **Post-hoc inference**:
   - expertise_a: Beginner > Intermediate (Δ ≈ +0.0235, p = .0261)
   - render_a
     - r1 > r2 (Δ ≈ +0.0657, p < .0001)
     - r1 > r3 (Δ ≈ +0.0688, p < .0001)
     - r2 ≈ r3 (ns)
Conclusion: Beginners score reliably higher than Intermediates overall. For render_a, r1 yields significantly higher score than r2 and r3, which do not differ from each other. Rendering is a major driver of variance in score, alongside substantial between-participant variability, with additional modulation by expertise level.
