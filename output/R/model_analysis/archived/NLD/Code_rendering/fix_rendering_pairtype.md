# Model Analysis

1. **Random Effects**: Random intercept SDs for exp_a = 0.01418 and exp_b = 0.02656; residual SD = 0.08539.
Adjusted ICC = 0.111, meaning that ~11% of the total variance in score is attributable to stable between-participant differences (small individual differences).
2. **Nakagawa R²**: Marginal R² = 0.0086; Conditional R² = 0.1183. PairType explains <1% of the variance; participant-level random effects account for an additional ~11%.
3. **Post-hoc inference**:
   - BB ≈ BI (Δ ≈ +0.00845, p = .6703)
   - BB ≈ II (Δ ≈ +0.02339, p = .2096)
   - BI ≈ II (Δ ≈ +0.01494, p = .4065)
  There is no evidence that PairType (BB, BI, II) reliably affects score. Fixed effects contribute negligibly to explained variance, and observed variability is dominated by between-participant differences rather than by pair composition.
