# Model Analysis

1. **Random Effects**: Random intercept SDs for exp_a = 0.01418 and exp_b = 0.02656; residual SD = 0.08539.
Adjusted ICC = 0.111, meaning that ~11% of the total variance in score is attributable to stable between-participant differences (small individual differences).
2. **Nakagawa R²**: Marginal R² = 0.0086; Conditional R² = 0.1183. Fixed effects (expertise_mean and expertise_diff) explain <1% of the variance; participant-level random effects account for an additional ~11%.
3. **Post-hoc inference**:
   - expertise_mean: β ≈ −0.0234, SE = 0.0139, z = −1.69, p = .0913. Trend-level negative association with score (not statistically significant at α = .05).
   - expertise_diff: β ≈ +0.00325, SE = 0.00832, z = 0.39, p = .6966. No evidence of an association with score.
  Conclusion: Neither expertise_mean nor expertise_diff reliably predicts score. The fixed effects contribute negligibly to explained variance, and most explainable structure in the data arises from between-participant variability rather than from expertise-related predictors.
